## 功能

- **开机自动认证**：登录进桌面就把校园网连上
- **断网自动重连**：计划任务每分钟检查一次，掉线自动补认证
- **图形界面**：填学号、密码 → 点【保存并安装】→ 完事；下次打开自动回填，不用重复输
- **免安装运行库**：内置 Python 3.12，电脑上不需要装 Python、不需要 pip
- **兼容代理软件**：Clash / Watt Toolkit 等开着也能用（校园网请求强制直连）
- **校外不卡界面**：连着手机热点时 2 秒内判断"不在校园网"，界面全程可操作
- **隐私**：账号密码用 Windows DPAPI **加密**后存在你自己电脑上（`%LOCALAPPDATA%\HTUAutoConnect\credentials.dat`），只有本机当前 Windows 用户能解开，不上传任何服务器
- **纯标准库**：100% Python 标准库实现，源码可读可改

## 快速开始

1. 到 [Releases](https://github.com/ccdyx-001/htu-campus-autoconnect/releases/latest) 下载 `htu-campus-autoconnect_v1.1.0.zip`（发布包用英文名，避免 GitHub 截断中文文件名），解压到任意位置（桌面也行）
2. 双击 **`点我启动.bat`**
3. 在窗口里填：**学号** → **上网密码** → 点【保存并安装】
4. 弹出管理员权限确认框时点 **【是】**（注册开机自启任务需要）
5. 完成。桌面会出现【校园网自动连接】图标，以后开机自动连

> 初始密码规则一般是 `Myhtu` + 身份证第 12-17 位，以学校通知为准。

## 工作原理

河师大用的是华为风格的 Portal 认证，`authByRas=false` 走明文：

```
1. 探测认证服务器：访问 http://www.msftconnecttest.com/redirect 等地址，
   被 AC 重定向后从 URL 里取出真实的 Portal 地址和 AC 名称（wlanacname）
2. 获取本机在校园网内的 IP：优先问 Portal 的 /portal/getRemoteAddr.do，
   其次 UDP 路由探测，最后枚举本机网卡（避开 Clash 的 198.18.x 虚拟网卡）
3. 提交认证：
   GET http://<portal>/quickauth.do?userid=<学号@htu>&passwd=<密码>&wlanuserip=<IP>&wlanacname=<AC>&...
   返回 JSON 里 code="0" 表示成功，"7" 表示账号密码错误
4. 断线检测：请求 generate_204 类地址，严格校验「HTTP 204 且未被 AC 劫持」
5. 时间校准：读认证服务器 HTTP 响应头的 Date 字段，提示系统时间是否有偏差
```

细节都写在 `程序文件\AutoConnect_htu.py` 的注释里，欢迎直接读源码。

## 数据与隐私（账号密码存在哪）

**一句话：账号密码只保存在你自己电脑上，程序不会把它们发到任何地方。**

点了【保存并安装】之后，程序会把自己复制到：

```
C:\Users\你的用户名\AppData\Local\HTUAutoConnect\
├── credentials.dat      ← 你的学号 + 上网密码（Windows DPAPI 加密，记事本打开是乱码）
├── .user                ← 你的学号（界面显示用，不含密码）
├── autoconnect.log      ← 运行日志（含学号和本机 IP）
└── runtime\             ← 内置的 Python 运行库
```

> 如果你没点安装、直接双击 `点我启动.bat` 使用，数据就存在**你解压的那个文件夹**里 ✓
> `%LOCALAPPDATA%` 是"当前 Windows 用户"的目录，所以**同一台电脑上不同账户的数据互不可见** ✓

### 程序会连哪些地址

| 地址 | 用途 |
|---|---|
| `http://10.101.2.194:6060` | 学校认证服务器（提交你的登录请求） |
| `http://www.msftconnecttest.com/redirect` | 探测是否被 AC 重定向（拿认证服务器地址） |
| `http://connect.rom.miui.com/generate_204`、`http://1.1.1.1` | 判断当前是否已联网 |

**就这四个，没有别的。** 程序里**没有任何上传 / 上报 / 统计 / 遥测代码** ——
你的账号只在你自己的电脑和学校认证服务器之间传递，作者那边收不到任何数据 ✓

### 安全边界（诚实说明）

- 账号文件 `credentials.dat` 用 **Windows DPAPI 加密**保存，密钥由 Windows 掌管，
  绑定「这台电脑 + 当前 Windows 登录账户」✓
  - 用记事本打开只能看到乱码，看不到密码 ✓
  - 复制到别的电脑 / 别的 Windows 账户 → 解不开（这是故意的）✓
  - 被别的软件改动过 → 解不开 ✓
  - 遇到这几种情况：重新填一次学号密码、点【保存并安装】即可恢复 ✓
- 从 v1.0.0 升级：第一次运行时会自动把旧的明文 `credentials.env`
  加密成 `credentials.dat`，并删除明文文件（升级失败会保留明文，保证功能不受影响）✓
- 仍然要说清楚：**程序运行期间密码在内存里**，本机管理员、或者能直接操作你这台电脑的人
  依然有办法拿到它。加密挡住的是"文件被拷走给别人看"和"别的用户偷看文件"，
  不能代替给电脑设登录密码 ⚠️
- 日志 `autoconnect.log` 里会记录学号与本机 IP（排查问题需要），不想留可以删 ✓

## 常见问题

**Q：双击没反应 / 闪退？**
确认 `程序文件` 文件夹还在、没有被改名或移动。

**Q：提示"没有检测到 Python"？**
本版本内置运行库。若出现该提示，说明你下载的是**源码**而不是 Release 里的发布包 ——
源码版需要自己装 Python 3.8+，或者去 Releases 下载免安装版。

**Q：我手动把程序文件夹删了，桌面图标点开提示"正在查找 pythonw.exe"？**
A：这是正常现象 —— 图标指向的是程序文件夹里的文件，文件被删了，Windows 自然就找不到了。
   两种修法（推荐第一种）：
   1. **一键修复**：双击下载包里的 `点我启动.bat` → 点【保存并安装】→ 程序文件会重新复制回去，
      计划任务、桌面图标、面板条目都会一起恢复 ✓（你的学号密码会被自动填好，不用重输）
   2. **彻底清理**：设置 → 应用 → 卸载 → 再删掉桌面上和开始菜单里的图标 ✓

   💡 **正确卸载方式**：双击 `卸载.bat`，或在「设置 → 应用」里卸载 ——
      这样图标、计划任务、账号文件都会一起清理干净，不会留下点不开的图标 ✓

**Q：杀毒软件报警或删除文件？**
个别杀软对"开机自启的小工具"敏感。把整个文件夹加入信任区即可
（火绒：设置 → 病毒防护 → 信任区 → 添加目录；360：木马查杀 → 信任区）。

**Q：连着手机热点，点【立即连接测试】会卡住吗？**
不会。程序会先花最多 2 秒判断是否在校园网，不在就直接提示
"当前已联网（不在校园网）"，界面全程可正常操作。

**Q：怎么卸载？**
双击 `卸载.bat`，或在「设置 → 应用」里卸载（安装版会自动出现在列表里）。

## 适配其他学校

认证协议是华为 Portal 的通用形态，换学校一般只需要改三处
（见 `程序文件\AutoConnect_htu.py` 顶部常量）：

```python
DEFAULT_PORTAL   = "http://10.101.2.194:6060"   # 认证服务器
DEFAULT_AC_NAME  = "HSD-BRAS-2"                 # AC 名称
DEFAULT_SUFFIX   = "@htu"                       # 账号后缀（教职工可能是 @htu.edu.cn）
```

如果你们学校用 `authByRas=true`（加密提交），需要按认证页面的参数补一部分逻辑。
