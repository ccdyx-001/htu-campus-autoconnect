============================================================
  河南师范大学  校园网自动连接工具   使用说明
============================================================

【它能做什么】
  · 每次开机自动连上校园网，不用再手动打开网页登录
  · 断网后自动重连（每分钟检查一次，一般 1 分钟内恢复）
  · 后台静默运行，没有任何窗口和弹窗


【怎么安装】
  1. 把整个文件夹解压到任意位置（建议放 D 盘等固定目录，不要放在
     临时目录或压缩包里直接运行）
  2. 双击  install.bat
  3. 按提示输入你的学号 和 上网密码
       · 账号 = 学号（不用自己加 @htu，程序会自动补上）
       · 初始密码规则： Myhtu + 身份证第 12-17 位
     → 如果提示“✅ 认证成功”，说明账号密码正确
  4. 弹出“管理员权限”确认框时，点【是】
  5. 看到“安装完成”就搞定了


【前提条件】
  · Windows 10 / 11
  · 电脑已安装 Python 3.8 或更高版本
      （官网 https://www.python.org/downloads/ ，
        安装时务必勾选 “Add Python to PATH”）
  · 校园网 Wi-Fi 已保存并勾选“自动连接”
      （Windows 设置 → 网络和 Internet → WLAN → 管理已知网络）


【常见问题】
  Q: 提示“没有检测到 Python”
  A: 去 https://www.python.org/downloads/ 安装，
     安装界面底部勾选 “Add Python to PATH”，装完重新运行 install.bat

  Q: 提示“账号或密码不正确”
  A: 检查学号和密码是否输入正确；初始密码是 Myhtu + 身份证第 12-17 位；
     如果改过密码，请用新密码

  Q: 开着代理（Clash / VPN）会不会失效？
  A: 不会。程序对校园网请求做了“强制直连”处理，已专门适配系统代理。
     但注意：如果代理软件开启了 TUN / 虚拟网卡模式，可能会影响校园网访问，
     建议关闭 TUN 模式，只保留“系统代理”模式。

  Q: 怎么确认它在正常工作？
  A: 打开同目录的 autoconnect.log 看记录：
       “当前已联网，无需认证”  = 网络正常，程序在守着
       “[OK] 认证成功！”       = 刚检测到掉线并自动帮你连上了
       “[FAIL] 账号或密码不正确” = 密码错了，重新运行 install.bat 改

  Q: 想改密码 / 换账号？
  A: 重新双击 install.bat，输入新的账号密码即可（会覆盖旧配置）

  Q: 电脑重启后还需要操作吗？
  A: 不需要。计划任务会在你登录进桌面时自动执行。

  Q: 怎么卸载？
  A: 双击 uninstall.bat，它会：
       · 删除开机自启的计划任务（不再自动连接）
       · 删除保存的账号密码文件 credentials.env
       · 询问是否立即断开校园网认证（10 秒内不选择则自动断开，
         断开后本机掉线，需要手动打开浏览器重新登录）
       · 询问是否删除运行日志（默认保留，10 秒内不选择即保留）


【安全说明】
  · 账号密码只保存在本机 credentials.env 文件里，不会上传到任何服务器
  · 程序只向学校认证服务器发送登录请求，不做其他网络操作
  · 源码完全公开（AutoConnect_htu.py），可自行查看核对
  · 运行 uninstall.bat 卸载时，账号密码文件会被删除；
    运行日志会在征求你同意后才删除（默认保留）


【出问题怎么办】
  把 autoconnect.log 的最后几行发给管理员/作者即可快速定位。
