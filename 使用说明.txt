============================================================
  河南师范大学  校园网自动连接   使用说明（免费开源版 v1.3.0）
============================================================

【这个文件夹里有什么】

    点我启动.bat     ← 双击这个（唯一的入口）
    卸载.bat         ← 不想用了双击这个
    使用说明.txt     ← 你正在看的这个
    程序文件\         ← 软件本体，不要动它

  就这么简单：平时只需要记住【点我启动.bat】这一个文件。


【第一次使用（三步）】

  1. 把整个文件夹解压到任意位置（桌面也行）

  2. 双击【点我启动.bat】，会弹出一个窗口

  3. 在窗口里填：
       学号 → 上网密码
     然后点【保存并安装】。弹出管理员权限确认框时点【是】，
     看到"安装完成"就好了。

  说明：本版本不需要注册码、不需要激活，填完学号密码就能用。
        密码默认是隐藏的，勾上【显示密码】可以核对有没有输错。


【安装之后（重要）】

  点完【保存并安装】，程序会把自己装到本机：

    · 程序文件 → C:\Users\你的用户名\AppData\Local\HTUAutoConnect
    · 桌面会出现一个【校园网自动连接】图标 ← 以后用这个打开界面
    · 开始菜单里也会有，另外"设置 → 应用"里多出一条，可以在那里卸载

  所以：装完之后，这个下载文件夹（以及压缩包）就可以删掉了，
  不影响使用。想留着也行，方便以后重装。


【如果你装的是单文件安装包（一个 exe，v1.2.0 新增）】

  如果你下载的是一个叫 htu-campus-autoconnect_v1.2.0_setup.exe 的文件，
  那么你手上是「单文件安装包」版，不用解压，用法更简单：

  安装：

    1. 双击那个 exe（不用解压，双击就行）
    2. 它自己会把程序装到：
         C:\Users\你的用户名\AppData\Local\HTUAutoConnect
       同时注册开机自启任务、建桌面和开始菜单快捷方式，
       并在"设置 → 应用"里登记一条
    3. 弹提示后，到桌面双击【校园网自动连接】
    4. 在窗口里填：学号 → 上网密码 → 点【保存并安装】
    5. 装完这个 exe 就可以删掉了

    · 首次双击可能等 2～5 秒才弹出提示，这是正常的：
      安装包要先把自己解压到临时目录再干活，不是卡死

  以后想改账号 / 重装 / 卸载：

    · 再双击一次那个 exe（如果还在的话），会弹出标题为"已安装"的小窗口，
      上面有三个按钮：
         【打开界面】      ← 和双击桌面图标一样
         【重新安装/更新】  ← 重新复制程序文件，已保存的学号密码会保留
         【卸载】          ← 会问你"保留还是删除账号文件"，自己选
    · exe 已经删了？那就到 设置 → 应用 → 河南师范大学 校园网自动连接 → 卸载

  安装包版和 zip 版有什么区别？

    · 功能完全一样，账号文件也不共享冲突（都放在同一个安装目录）
    · 安装包版省掉"解压 + 双击点我启动.bat"两步，更适合直接发给同学
    · 安装包版开机自启这一条：非管理员能成功注册"每 1 分钟检查"，
      "登录时立刻触发"需要管理员权限，安装器会自动退化成每分钟检查
      （登录后最多 1 分钟就会自动连上）。
      想要登录瞬间就连上：右键那个 exe → 以管理员身份运行，再装一次

    · 小提示：点【保存并安装】或【卸载】时会弹管理员权限确认框，
      点完之后可能闪过一下黑色命令行窗口，属正常现象（不影响功能）


【右下角的托盘图标（怎么知道程序还开着）】

  v1.3.0 新增：打开界面后，屏幕右下角（托盘区）会出现一个图标。
  它就是你判断"程序到底关了没有"的依据：

    · 有图标  → 程序还开着
    · 没图标  → 进程已经退出（真的关了）

  怎么用：

    · 鼠标移到图标上 → 显示当前状态，例如：
        校园网自动连接 v1.3.0 ｜ 网络：已联网 ｜ 自动连接：已安装
    · 双击图标 → 打开界面（窗口缩到托盘后也是这样叫回来）
    · 右键图标 → 菜单里有四个：
        打开界面 / 立即连接测试 / 查看状态 / 退出

  关闭的时候会发生什么（说清楚，不用猜）：

    · 点窗口右上角的【X】 → 真的退出程序，托盘图标跟着消失。
      这时会弹一个气泡提示："程序已退出，右下角图标会消失。
      开机自动连由计划任务负责，不受影响。"
    · 点窗口的【最小化】  → 缩到托盘：窗口藏起来，托盘图标留着。
      气泡会提示"双击图标可以打开"。

  重要：界面退出**不影响自动连网**。开机自动认证、断网自动重连是
  Windows 计划任务在负责，和这个窗口开不开没关系。


【以后怎么用】

  什么都不用做！开机进入桌面后，它会自动连上校园网。
  中途掉线也会在 1 分钟内自动重连。

  想看状态 / 换账号密码：双击桌面上的【校园网自动连接】。
  窗口底部会显示两行：

     网络：已联网          自动连接：已安装（Ready / 上次结果 0）
     账号：已保存（Windows 加密，开机自动连）

  都正常，就说明它在正常守候。


【账号密码存在哪里（安全说明）】

  · 账号密码保存在本机，文件名是 credentials.dat，
    安装后在 C:\Users\你的用户名\AppData\Local\HTUAutoConnect 里
  · 用的是 Windows 自带的 DPAPI 加密：密钥由 Windows 掌管，
    绑定"这台电脑 + 当前 Windows 登录账户"
       - 文件被复制到别的电脑 → 解不开
       - 换了 Windows 登录账户 → 解不开
       - 文件被别的软件改动过 → 解不开
    遇到这几种情况，重新填一次学号密码、点【保存并安装】即可恢复
  · 不需要你额外记密码，程序运行时自动解密（开机自动连照常工作）
  · 用记事本打开 credentials.dat 只能看到乱码，看不到你的密码
  · 老版本（v1.0.0）的明文账号文件 credentials.env 会在第一次运行时
    自动升级成加密文件，并删除原来的明文文件
  · 不会上传到任何服务器：程序只向学校认证服务器（10.101.2.194:6060）
    和联网检测地址发送请求
  · 源码是纯文本（程序文件\AutoConnect_htu.py），可自行查看核对
  · 想彻底清除账号：卸载时选择"删除账号文件"，或手动删掉 credentials.dat


【常见问题】

  Q: 双击没反应 / 闪退？
  A: 确认【程序文件】文件夹还在、没有被改名或移动。

  Q: 桌面上的图标双击没反应，提示"正在查找 pythonw.exe"？
  A: 说明本机装好的那份程序被删掉了（手动删文件夹就会这样）。
     修法一（推荐）：双击下载包里的【点我启动.bat】→ 点【保存并安装】，
        程序会重新复制回去，计划任务和图标都会恢复。
     修法二（彻底清理）：设置 → 应用 → 卸载，再删掉桌面上那个图标。

  Q: 提示"没有检测到 Python"？
  A: 发布包内置了运行库，不需要装 Python。
     如果看到这个提示，说明你下载的是源码（而不是 Release 里的发布包），
     要么去 Releases 下载发布包，要么自己装 Python 3.8 以上。

  Q: 提示"账号或密码不正确"
  A: 检查学号和密码。初始密码规则： Myhtu + 身份证第 12-17 位

  Q: 提示"账号文件解不开"？
  A: 这是加密的正常表现：账号文件只能在这台电脑的这个 Windows 账户里解开。
     常见原因：把程序文件夹从别的电脑拷过来 / 换了 Windows 登录账户 /
     文件被工具软件改动过。
     解决办法：重新输入一次学号和上网密码，点【保存并安装】即可。

  Q: 正确的卸载方式是什么？
  A: 双击【卸载.bat】，或者在 设置 → 应用 → 河南师范大学 校园网自动连接 → 卸载。
     （装的是单文件安装包的话：再双击一次那个 ..._setup.exe → 点【卸载】）
     卸载过程会问你：要不要保留账号文件？你自己选：
       · 保留：以后重装不用重新输密码，直接就能用
       · 删除：账号密码不再留在本机
     直接删文件夹会留下点不开的图标，不推荐。

  Q: 连着手机热点 / 家里网，点【立即连接测试】会不会卡住？
  A: 不会。程序会先花最多 2 秒确认"在不在校园网"，不在就直接告诉你
     "当前已联网（不在校园网）"，界面全程可以正常操作（不会出现"无响应"）。
     这是正常的：校外网连不上学校认证服务器，回学校连上 HTU_Student 就好。

  Q: 开着代理（Clash / VPN）会不会失效？
  A: 不会。程序对校园网请求做了"强制直连"处理。
     但建议不要开 TUN 模式（那会接管所有流量）。

  Q: 换了电脑 / 重装了系统怎么办？
  A: 重新解压一份，双击【点我启动.bat】，重新填一次学号密码就行。
     （加密绑定电脑和账户，所以账号文件不能直接拷过去用，这是故意的）


【如果杀毒软件报警 / 文件被删了】

  个别杀毒软件（如火绒、360）可能对这类"自动运行"的小工具比较敏感，
  误判并删除文件。如果遇到：

    装的是解压版（zip）：
      · 火绒：设置 → 病毒防护 → 信任区 → 添加目录 → 选择本文件夹
      · 360 ：木马查杀 → 右下角"信任区" → 添加目录
      加完之后，重新解压一份即可正常使用。

    装的是单文件安装包（..._setup.exe）：
      · 被拦的是那个 exe 本身 —— 先把 exe 加进信任区，
        再把安装目录也加进去：
          C:\Users\你的用户名\AppData\Local\HTUAutoConnect
      · 火绒添加文件：设置 → 病毒防护 → 信任区 → 添加文件 → 选中那个 exe
      · 说明：单文件安装包是"自解压"形态，天生比普通程序更容易被误判，
        这一版已经去掉了脚本里最容易被盯上的特征字串（隐藏窗口 + 绕过执行策略），
        但仍不能保证 100% 不误报

  实在过不去杀软的，改用解压版（zip + 点我启动.bat）通常就没问题。


【注意事项】

  · 安装前不要移动、改名或删除【程序文件】文件夹
    （安装完成后就可以随便删了）
  · 出问题时，把 autoconnect.log 最后几行发给作者
    （在安装目录里：C:\Users\你的用户名\AppData\Local\HTUAutoConnect）
  · 只适配河南师范大学的认证接口；其他学校需要改接口参数（见 README）
