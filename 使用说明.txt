============================================================
  河南师范大学  校园网自动连接   使用说明（免费开源版 v1.1.0）
============================================================

【这个文件夹里有什么】

    点我启动.bat     ← 双击这个（唯一的入口）
    卸载.bat         ← 不想用了双击这个
    使用说明.txt     ← 你正在看的这个
    程序文件\         ← 软件本体，不要动它

  就这么简单：平时只需要记住【点我启动.bat】这一个文件。


【第一次使用（三步）】

  1. 把整个文件夹解压到任意位置（桌面也行）

  2. 双击【点我启动.bat】，会弹出一个窗口

  3. 在窗口里填：
       学号 → 上网密码
     然后点【保存并安装】。弹出管理员权限确认框时点【是】，
     看到"安装完成"就好了。

  说明：本版本不需要注册码、不需要激活，填完学号密码就能用。
        密码默认是隐藏的，勾上【显示密码】可以核对有没有输错。


【安装之后（重要）】

  点完【保存并安装】，程序会把自己装到本机：

    · 程序文件 → C:\Users\你的用户名\AppData\Local\HTUAutoConnect
    · 桌面会出现一个【校园网自动连接】图标 ← 以后用这个打开界面
    · 开始菜单里也会有，另外"设置 → 应用"里多出一条，可以在那里卸载

  所以：装完之后，这个下载文件夹（以及压缩包）就可以删掉了，
  不影响使用。想留着也行，方便以后重装。


【以后怎么用】

  什么都不用做！开机进入桌面后，它会自动连上校园网。
  中途掉线也会在 1 分钟内自动重连。

  想看状态 / 换账号密码：双击桌面上的【校园网自动连接】。
  窗口底部会显示两行：

     网络：已联网          自动连接：已安装（Ready / 上次结果 0）
     账号：已保存（Windows 加密，开机自动连）

  都正常，就说明它在正常守候。


【账号密码存在哪里（安全说明）】

  · 账号密码保存在本机，文件名是 credentials.dat，
    安装后在 C:\Users\你的用户名\AppData\Local\HTUAutoConnect 里
  · 用的是 Windows 自带的 DPAPI 加密：密钥由 Windows 掌管，
    绑定"这台电脑 + 当前 Windows 登录账户"
       - 文件被复制到别的电脑 → 解不开
       - 换了 Windows 登录账户 → 解不开
       - 文件被别的软件改动过 → 解不开
    遇到这几种情况，重新填一次学号密码、点【保存并安装】即可恢复
  · 不需要你额外记密码，程序运行时自动解密（开机自动连照常工作）
  · 用记事本打开 credentials.dat 只能看到乱码，看不到你的密码
  · 老版本（v1.0.0）的明文账号文件 credentials.env 会在第一次运行时
    自动升级成加密文件，并删除原来的明文文件
  · 不会上传到任何服务器：程序只向学校认证服务器（10.101.2.194:6060）
    和联网检测地址发送请求
  · 源码是纯文本（程序文件\AutoConnect_htu.py），可自行查看核对
  · 想彻底清除账号：卸载时选择"删除账号文件"，或手动删掉 credentials.dat


【常见问题】

  Q: 双击没反应 / 闪退？
  A: 确认【程序文件】文件夹还在、没有被改名或移动。

  Q: 桌面上的图标双击没反应，提示"正在查找 pythonw.exe"？
  A: 说明本机装好的那份程序被删掉了（手动删文件夹就会这样）。
     修法一（推荐）：双击下载包里的【点我启动.bat】→ 点【保存并安装】，
        程序会重新复制回去，计划任务和图标都会恢复。
     修法二（彻底清理）：设置 → 应用 → 卸载，再删掉桌面上那个图标。

  Q: 提示"没有检测到 Python"？
  A: 发布包内置了运行库，不需要装 Python。
     如果看到这个提示，说明你下载的是源码（而不是 Release 里的发布包），
     要么去 Releases 下载发布包，要么自己装 Python 3.8 以上。

  Q: 提示"账号或密码不正确"
  A: 检查学号和密码。初始密码规则： Myhtu + 身份证第 12-17 位

  Q: 提示"账号文件解不开"？
  A: 这是加密的正常表现：账号文件只能在这台电脑的这个 Windows 账户里解开。
     常见原因：把程序文件夹从别的电脑拷过来 / 换了 Windows 登录账户 /
     文件被工具软件改动过。
     解决办法：重新输入一次学号和上网密码，点【保存并安装】即可。

  Q: 正确的卸载方式是什么？
  A: 双击【卸载.bat】，或者在 设置 → 应用 → 河南师范大学 校园网自动连接 → 卸载。
     卸载过程会问你：要不要保留账号文件？你自己选：
       · 保留：以后重装不用重新输密码，直接就能用
       · 删除：账号密码不再留在本机
     直接删文件夹会留下点不开的图标，不推荐。

  Q: 连着手机热点 / 家里网，点【立即连接测试】会不会卡住？
  A: 不会。程序会先花最多 2 秒确认"在不在校园网"，不在就直接告诉你
     "当前已联网（不在校园网）"，界面全程可以正常操作（不会出现"无响应"）。
     这是正常的：校外网连不上学校认证服务器，回学校连上 HTU_Student 就好。

  Q: 开着代理（Clash / VPN）会不会失效？
  A: 不会。程序对校园网请求做了"强制直连"处理。
     但建议不要开 TUN 模式（那会接管所有流量）。

  Q: 换了电脑 / 重装了系统怎么办？
  A: 重新解压一份，双击【点我启动.bat】，重新填一次学号密码就行。
     （加密绑定电脑和账户，所以账号文件不能直接拷过去用，这是故意的）


【如果杀毒软件报警 / 文件被删了】

  个别杀毒软件（如火绒、360）可能对这类"自动运行"的小工具比较敏感，
  误判并删除文件。如果遇到，请把本文件夹加入杀软的信任区：

    · 火绒：设置 → 病毒防护 → 信任区 → 添加目录 → 选择本文件夹
    · 360 ：木马查杀 → 右下角"信任区" → 添加目录

  加完之后，重新解压一份即可正常使用。


【注意事项】

  · 安装前不要移动、改名或删除【程序文件】文件夹
    （安装完成后就可以随便删了）
  · 出问题时，把 autoconnect.log 最后几行发给作者
    （在安装目录里：C:\Users\你的用户名\AppData\Local\HTUAutoConnect）
  · 只适配河南师范大学的认证接口；其他学校需要改接口参数（见 README）
